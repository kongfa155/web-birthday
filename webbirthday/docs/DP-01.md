# DP-01 (Checkpoint B1): Dọn mã nguồn cũ không dùng và chuẩn hóa tài liệu cấu trúc

## Phạm vi & Điểm khởi chạy (Entrypoints)

Checkpoint B1 của DP-01 chỉ gỡ bỏ các file cũ đã được chứng minh không còn đường dẫn import nào từ các entrypoint hiện hành (bao gồm cả dynamic `import()`), đồng thời chuyển phần hướng dẫn phân lớp từ các file `read.txt` vào tài liệu này.

- **Frontend entrypoint**: `src/main.jsx` -> `src/app/App.jsx` -> `src/app/routes.jsx`
- **Backend entrypoint**: `backend/server.js` -> `backend/app.js`

## Quy ước phân lớp (Layer Ownership)

Tổng hợp và chuẩn hóa từ các ghi chú `read.txt` trước đây:

- **`src/pages/`**: Chứa các component cấp trang (mỗi trang một thư mục riêng cùng CSS/module và subcomponent nội bộ của trang đó).
- **`src/components/common/`** (cùng `src/components/auth/`, `src/components/design/`): Chứa các thành phần giao diện dùng chung (button, input, header, footer, modal, auth guards, bộ xem thiệp). Chỉ đưa component vào `components/common` khi thực sự dùng chung giữa nhiều trang.
- **`src/services/`**: Chứa logic gọi API và xử lý giao tiếp dữ liệu phía sau, tách biệt khỏi logic hiển thị trực tiếp trên giao diện.
- **`backend/middlewares/`**: Chứa middleware xác thực (`auth.js`), giới hạn tần suất (`rateLimit.js`), kiểm tra đầu vào (validation) và xử lý lỗi.
- **`backend/utils/`**: Chứa các hàm tiện ích dùng chung cho backend (ví dụ: xử lý ngày tháng, email, token/nonce, schema/design helpers, và `backend/utils/processFabricEdit.js` đang được controller sử dụng).

- `src/pages/EditPage/PanelContext.js`: Chỉ được import bởi `WorkSpace.jsx`, `Toolbox.jsx`, `PropertiesPanel.jsx`, `LayerPanel.jsx`.
- `src/pages/EditPage/Toolbox.jsx`: Không được import ở đâu.
- `src/pages/EditPage/PropertiesPanel.jsx`: Không được import ở đâu.

### 2. Nhóm helper frontend cũ (không còn được sử dụng)
- `src/utils/processFabricEdit.js`: Không được import ở đâu (luồng backend sử dụng `backend/utils/processFabricEdit.js`, không liên quan file frontend này).

- `src/utils/fabricUtils.js`: Không được import ở đâu.
- `src/utils/extractImageURLs.js`: Không được import ở đâu.

### 3. Nhóm route & middleware upload backend cũ (không được mount)
- `backend/routes/upload.js`: Không được mount trong `backend/app.js` hay import ở đâu (backend hiện dùng `backend/routes/uploadBase64.js`).
- `backend/routes/uploadJSON.js`: Không được mount trong `backend/app.js` hay import ở đâu.
- `backend/middlewares/upload.js`: Chỉ được import bởi `backend/routes/upload.js`.

### 4. Các file ghi chú giữ chỗ (`read.txt`)
